# Job Match By Resume

A resume-to-job matching web application that ranks jobs using TF-IDF relevance and semantic embedding similarity.

## Features
- Resume text input
- Resume PDF upload
- TF-IDF ranking
- Semantic similarity scoring
- Expandable job details
- Pagination for results
- React frontend + Flask backend

## Tech Stack
Frontend:
- React
- Vite

Backend:
- Flask
- pandas
- scikit-learn
- sentence-transformers
